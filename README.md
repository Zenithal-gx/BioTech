# BioTech 🧬

Навчальний інструмент для розрахунків та біоінформатики на Python. Проєкт створено для автоматизації базових біоінформатичних завдань та роботи з нуклеїновими кислотами.

## Основні можливості
* Розрахунок характеристик нуклеїнових кислот та аналіз послідовностей.
* Зручний графічний інтерфейс, створений за допомогою бібліотеки `CustomTkinter`.
* Можливість роботи з тестовими файлами даних (наприклад, форматом `.fasta`, завантаженими з відкритих баз даних на кшталт NCBI).

## Використані технології
* **Python**
* **CustomTkinter** (для сучасного інтерфейсу)
